# Living Phone v2
Dark-mode installable PWA prototype built from scratch.

## Included now
- Home + dark phone aesthetic
- Shared Contacts with Nela, Mom, and Stray Kids members
- Current slow-burn long-distance-friends Canon
- Instagram and Echo interactive prototypes
- Diary CRUD
- Voice Memo AI entry point (provider hook; synthetic voices only)
- Music + Spotify configuration entry point
- Original Tracks kept separate from Voice Memos
- Generate Day review-first workflow
- Edit Mode and persistent local data
- PWA manifest/service worker
- Shells for Messages, Gallery, Calls, Browser, Calendar, Notes

## External services still needed for real generation/playback
Real AI images, TTS/audio, music generation, cloud AI Generate Day, and Spotify playback require provider credentials and deployment callback URLs. The UI deliberately does not fake successful generation/playback.
